Project Nightingale

A mid-size tech company is launching Mobile App v3.0 on April 15, 2026 — a redesigned one-tap checkout and a new loyalty program called Perks.

The PM (Sam Torres) and TPM (Rachel Nguyen) are flooded with questions from every team — engineering wants to know rollback plans, marketing wants press embargo details, the VP wants a 30-second status read.

Technical Architecture

Built entirely with Claude (claude-sonnet-4-6) via the Anthropic API. No ElevenLabs. No backend server. Runs entirely in this browser.

Multi-Agent Orchestration
Each agent has its own system prompt + scoped KB. The router detects ROUTE: agent signals in Claude's response and transparently switches agents mid-conversation.
Knowledge Base Scoping
3 KB files embedded in JS. Each agent only receives the files relevant to its domain — enforcing information boundaries without code-level access control.
Voice I/O
STT via Web Speech API (browser mic). TTS via SpeechSynthesis — Daniel/Inter voice, rate 0.92, pitch 0.88.
Conversation Memory
Full message history passed to Claude on every turn — agents remember what was said earlier in the session across routing hops.
